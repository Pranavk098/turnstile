What it does

Prices every span

ASR, LLM, tools, TTS and telephony are priced span by span from a dated rate card, per call and per turn.

Finds ten waste classes

Named detectors flag over-modeling, context bloat, reprompt loops, barge-in waste, silence, late escalation and more.

Proves the fix

The one remedy it can execute is replayed on a cheaper path. A saving only counts if the outcome is preserved.

Three honesty tiers

Proven

Savings the replay engine confirms: the cheaper path produced the same outcome, so the saving is real. This is the only number that counts as recovered.

Measured

Numbers from real synthesis or exact arithmetic, with confidence intervals. Strong evidence, stated with its provenance.

Conditional

Waste we detected and priced, where the fix has not been verified to preserve the outcome yet. Never mixed into the proven number.

Serve the folder first: python -m http.server from packages/dashboard, then open index.html over http — browsers block local-file data loads, so file:// shows an error instead of the dashboard.

Static, offline, no backend, no network. The dashboard renders pre-computed JSON and computes no cost or metric itself. Docs: METHOD.md and LIMITATIONS.md spell out exactly what is measured, what is modeled, and what is not yet measured.
