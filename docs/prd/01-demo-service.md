# PRD 01 — Deployed live eval service + demo front-end

**Owner (spec):** Pranav Koduru · **Executor:** OpenCode · **Reviewer:** Claude
**Status:** ready to build · **Roadmap item:** #1 (clickable, zero-install demo)

---

## 1. Thesis

Turnstile today is a library plus a static report you can only see after a full
local install (uv, WSL, local models, keys). A hiring manager or a curious
engineer has nothing to click. This feature ships a **single public URL** that,
in under five seconds and with zero install, shows a priced voice call, its
resolution verdict, and a Detector-7 (barge-in) finding — and lets a visitor
**paste their own call and get a live eval back**, computed by the existing
deterministic engine.

Because roadmap item #1 was chosen as a *deployed live service* (not a static
export), this PRD stands up a thin **FastAPI service that wraps the existing pure
engine** and serves the front-end from the same origin. It deliberately absorbs
the minimum of the future "paid live replay" work (roadmap #3) — the service runs
**only the deterministic, $0 path** (MockBackend replay), never a paid model call.

## 2. Non-goals

- **No paid anything.** No live LLM/ASR/TTS calls, no GPU, no paid hosting tier.
  See §3.
- **No new eval semantics.** The service exposes the engine that already exists;
  it does not invent metrics or change any frozen contract (`turnstile-prd.md`
  §3–5).
- **No auth, accounts, persistence, or multi-tenant storage.** Stateless request →
  eval → response. Uploaded calls are processed in-memory and not retained.
- **No front-end framework / Node build** unless §7 explicitly opts in. The repo
  has zero JS tooling today; keep it that way for v1.
- Not the paid open-loop replay (that stays roadmap #3).

## 3. Hard constraints (non-negotiable, apply to every phase)

1. **$0 to run and host.** Free-tier only. The acceptance demo must cost nothing
   to serve and nothing to exercise. **No code path in this feature may make a
   paid API call.** Replay uses the existing `MockBackend` and is labeled
   "mechanism, not a measured production rate," exactly as `build_data.py` and
   `docs/DEMO.md` already do.
2. **Engine purity is preserved.** The service is a shell. It imports and calls
   `turnstile_ingest.pipeline.run_calls` / the package entry points
   (`price_trace`, `adjudicate`, `detect`, `replay`/`experiment`) and adds **no
   business math of its own**. No re-pricing, no re-implemented detector. If a
   number is needed, it comes from the engine.
3. **Honesty labels survive to the wire.** Every JSON the API returns carries the
   same provenance/tier notes the pipeline already emits (measured /
   instrumented / mock-replay). The API must not strip them.
4. **Frozen contracts untouched.** No edits to `packages/schema`, `packages/pricing`
   formulas, or PRD §3–5 interfaces.
5. **Deterministic.** Same input → same output. No wall-clock, no RNG without a
   fixed seed, in any response body.

## 4. Architecture

```
                 ┌─────────────────────────── one free-tier container ──────────────┐
 visitor ──URL──▶│  FastAPI app                                                      │
                 │   ├── GET  /health                    → {"ok": true, "commit":…}  │
                 │   ├── GET  /api/fleet                  → prebuilt demo fleet JSON  │
                 │   ├── GET  /api/calls                  → list of demo call ids     │
                 │   ├── GET  /api/calls/{id}             → one prebuilt call report  │
                 │   ├── POST /api/evaluate               → run_calls(user IngestCall)│
                 │   └── StaticFiles("/")                 → front-end (index/home)    │
                 └───────────────────────────────────────────────────────────────────┘
                          │ imports, never re-implements
                 ┌────────▼─────────────────────────────────────────────────────────┐
                 │ existing pure engine: ingest.pipeline.run_calls                    │
                 │   price_trace → adjudicate → detect → MockBackend replay           │
                 └────────────────────────────────────────────────────────────────────┘
```

- **New package:** `packages/service/` (`turnstile_service`), one FastAPI app
  (`app.py`) + an entry point `turnstile_service.app:app`. Add `fastapi` and a
  server (`uvicorn[standard]`) to that package's `pyproject.toml` only — do not
  pollute other packages' deps.
- **Single origin.** FastAPI mounts the front-end via `StaticFiles`, so there is
  **no CORS surface** and the front-end and API deploy together.
- **Prebuilt fleet = instant first paint.** `GET /api/fleet` and the call reports
  are served from a JSON artifact **committed to the repo** (regenerated by the
  existing `build_data.py` / `turnstile_ingest` over the golden fixtures and the
  ingest sample). This means the page renders fully even if the container is cold
  — the cold-start of a free host never blocks first paint. Live compute happens
  only on `POST /api/evaluate`, which a visitor triggers deliberately.

### 4.1 `POST /api/evaluate` contract

- **Request body:** one `IngestCall` object, a `{"calls":[...]}` callset, or a
  bare list — the *exact* external ingest format in `docs/INGEST.md`
  (`turnstile_ingest.model.IngestCall`). `extra="forbid"` already gives loud,
  field-pathed validation; surface that as HTTP 422 with the field path.
- **Limits:** reject bodies over a fixed size (e.g. 1 MB) and callsets over a
  fixed call count (e.g. 25) with HTTP 413 — a public $0 endpoint must be
  DoS-bounded.
- **Response:** the **same `data.json` shape** `run_calls` already produces (fleet
  + findings + per-call reports + coverage + provenance). The front-end already
  knows how to render this shape — no new response schema is invented.
- **Errors:** malformed input → 422 with the `turnstile_ingest` error string;
  never a 500 for user-input problems; 500 only for genuine server faults, logged.

## 5. Front-end (v1: enhanced static, single origin)

Reuse `packages/dashboard/index.html` + `home.html` as the base. Two changes only:
1. Point their data `fetch` at the service's `/api/*` endpoints (with the committed
   JSON as an inline fallback so the file still opens locally).
2. Add one **"Evaluate your own call"** panel: a textarea prefilled with the
   `docs/INGEST.md` example, a **Run eval** button that `POST`s to
   `/api/evaluate`, and a results area that renders the returned report using the
   *existing* call-detail rendering. Show the loud 422 field path inline on bad
   input. Show a "computing…" state so a cold-start POST reads as working, not
   broken.

Keep it framework-free (vanilla JS + the existing CSS). A React/Solid rewrite is
explicitly deferred to §10.

## 6. Build phases (each ends with a runnable verify)

- **P0 — Service skeleton.** `packages/service` with FastAPI `app`, `/health`
  returning commit SHA, `uvicorn` runnable locally.
  *Verify:* `uv run uvicorn turnstile_service.app:app` serves `/health` 200.
- **P1 — Read endpoints over committed JSON.** `/api/fleet`, `/api/calls`,
  `/api/calls/{id}` served from the committed artifact; provenance notes intact.
  *Verify:* `pytest` via `fastapi.testclient` asserts shapes + a provenance key on
  each; numbers equal the CLI's `data.json` byte-for-byte for the same fixtures.
- **P2 — `POST /api/evaluate`.** Wire to `run_calls`; size/count limits; 422 on bad
  input with field path.
  *Verify:* tests for (a) the `INGEST.md` example → a report with a known finding,
  (b) a misspelled field → 422 with the path, (c) oversized body → 413, (d) the
  posted example yields the *same* report as the CLI on the same input.
- **P3 — Front-end wiring + evaluate panel.** Static served at `/`; fetches hit the
  API; evaluate panel round-trips.
  *Verify:* a headless page test (or a documented manual script) loads `/`, sees
  the fleet, posts the example, renders a finding. First paint works with the API
  stopped (fallback JSON).
- **P4 — Containerize + free-tier deploy + CI.** One `Dockerfile` (uv-based, slim,
  no local models); deploy to a free host (Fly.io free / Render free / Hugging
  Face Spaces Docker — pick one and document why); GitHub Actions deploys on push
  to the default branch.
  *Verify:* the public URL is live, `/health` 200, page loads < 5 s on a cold
  container (first paint from committed JSON), a posted example returns a report.
  Document the exact monthly cost = **$0** and the free-tier limits relied on.

## 7. Definition of Done (prod-ready / feature-ready)

- [ ] Public URL loads the fleet view with **no install and no auth**, first paint
      under 5 s even on a cold free-tier container.
- [ ] A visitor can drill into a single call (flame graph + findings + verdict) and
      see a Detector-7 barge-in finding with its honesty label.
- [ ] A visitor can paste the `INGEST.md` example (or their own call) and get a live
      eval report back from `POST /api/evaluate`.
- [ ] **Zero paid calls, $0 hosting** — proven by: no `OPENAI_API_KEY` / paid gate
      in any request path, and a documented free-tier deployment.
- [ ] Malformed input fails loud (422 + field path), never a 500; endpoint is
      size/count bounded.
- [ ] `uv run pytest` green including new `packages/service/tests`; total suite
      still green (currently 939 passed / 4 skipped — must not regress).
- [ ] API responses carry the same provenance/tier labels as the CLI artifact.
- [ ] `README` demo link and a new `docs/DEPLOY.md` document the URL, the host, the
      $0 claim, redeploy steps, and cold-start behavior.
- [ ] CI redeploys on push to the default branch and is green.

## 8. Test requirements

- `fastapi.testclient` unit/integration tests for every endpoint (happy path +
  the four `/api/evaluate` error/limit cases above).
- A **parity test**: `POST /api/evaluate` on a fixture equals
  `run_calls` on the same fixture (guards against the service drifting from the
  engine).
- A provenance-retention test (labels present on every returned report).
- Determinism test: two identical POSTs return identical bodies.

## 9. Risks

| Risk | Sev | Mitigation |
|---|---|---|
| Free host cold-start makes the demo feel dead | High | First paint from committed JSON; "computing…" state on POST; document expected cold-start; optionally a cheap keep-warm ping via a free scheduler (no paid tier) |
| Free-tier limits change / host sunsets | Med | Dockerized + one-file deploy config → portable across free hosts; `docs/DEPLOY.md` records the fallback host |
| A visitor posts abusive payloads | Med | Hard size/count caps (413), in-memory only, no persistence, no outbound calls |
| Service silently diverges from engine numbers | Med | Parity test in §8 fails CI if it does |

## 10. Out of scope / future (do not build now)

- Paid live-model replay (roadmap #3).
- React/Solid front-end rewrite (only if the evaluate UX outgrows vanilla JS).
- Auth, saved runs, historical dashboards, multi-user.
