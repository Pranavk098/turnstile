# Turnstile

Voice-AI margin profiler: price every turn, adjudicate resolution, detect
waste, prove savings by replay.

- **Live demo:** [https://turnstile-demo.onrender.com](https://turnstile-demo.onrender.com)
- **PyPI:** [turnstile packages on PyPI](https://pypi.org/search/?q=turnstile) (`pip install turnstile-<pkg>` after a release tag; see the [release workflow](https://github.com/Pranavk098/turnstile/blob/main/.github/workflows/release.yml))
- **Source:** [GitHub](https://github.com/Pranavk098/turnstile)

## Honesty rule

This site states no numbers of its own. Every figure lives in its source
doc — [METHOD.md](METHOD.md), [PERF.md](performance.md), or the calibration
report — and every page here links there instead of repeating values.
